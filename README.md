# Pratham Raj Portfolio

Modern personal portfolio for Pratham Raj, built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

```bash
npm install
npm run dev
npm run build
```

## Deploy

Use these settings on Vercel, Netlify, or any static host:

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

The included `vercel.json` rewrites all routes to `index.html`, so the site is safe for direct links and refreshes.
